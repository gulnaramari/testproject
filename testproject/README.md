### Веб-приложение с API-интерфейсом

## 1.Зачем нужно приложение:

Реализована модель сети по продаже электроники.
Сеть должна представлять собой иерархическую структуру из трех уровней:
* -Завод;
* -Розничная сеть;
* -Индивидуальный предприниматель.

## 2.Возможности приложения:

* Каждое звено сети ссылается только на одного поставщика оборудования (не обязательно предыдущего по иерархии).
* уровень иерархии определяется не названием звена, а отношением к остальным элементам сети,
* т. е. завод всегда находится на уровне 0, а если розничная сеть относится напрямую к заводу,
* минуя остальные звенья, ее уровень — 1
* -Каждое звено сети должно обладать следующими элементами:
* Название.
* Контакты:
* -email,
* -страна,
* -город,
* -улица,
* -номер дома.
* Продукты:
* -название,
* -модель,
* -дата выхода продукта на рынок.
* Поставщик (предыдущий по иерархии объект сети).
* Задолженность перед поставщиком в денежном выражении с точностью до копеек.
* Время создания (заполняется автоматически при создании).
* -Сделан вывод в админ-панели созданных объектов.
* На странице объекта сети добавлены:
* ссылка на «Поставщика»;
* фильтр по названию города;
* admin action, очищающий задолженность перед поставщиком у выбранных объектов.
* фильтрация объектов по определенной стране.
* права доступа к API у активных сотрудников.

## 3. Особенности приложения:

* Веб-приложение реализовано на фреймворке Django
* Авторизация пользователя
* Регистрация пользователя
* Документация по API с Swagger

## 5. Развертывание на сервере с помощью docker-compose (локально)

Требования:
* Для успешного развертывания вам понадобятся:
* Удаленный сервер с установленным Docker.
* Учетная запись Docker Hub. 
* Клонирование репозитория: git clone https://github.com/gulnaramari/testproject.git
* Переименуйте файл '.env.sample' в '.env' 
* внесите необходимые данные переменных окружения.
* Разрешенные хосты=localhost,127.0.0.1,example.com
* Запустите проект командой: docker-compose up -d --build
* Аварийные Команды (Сервер)
* Просмотр логов: docker-compose logs -f
* Остановка и удаление контейнеров: docker-compose down
